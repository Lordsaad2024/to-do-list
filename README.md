# to-do-list

قائمة مهام بسيطة لإدارة عملك وتقسيم المهام.

## وصف المشروع
مشروع "to-do-list" هو تطبيق ويب بسيط يساعدك على إنشاء، تعديل، وحذف المهام اليومية. الهدف تقديم واجهة سهلة وسريعة لتنظيم العمل الشخصي أو المهام المهنية الصغيرة.

الميزات الأساسية:
- إضافة مهمة مع عنوان ووصف واختيار تاريخ انتهاء (اختياري).
- تمييز المهام كمكتملة/غير مكتملة.
- تعديل وحذف المهام.
- تخزين البيانات محليًا (Local Storage) أو عبر واجهة خلفية بسيطة.

التقنيات المستخدمة:
- JavaScript
- HTML
- CSS

## خطة العمل (خطة تنفيذ المشروع)
1. إعداد هيكل المشروع
   - إنشاء ملفات `index.html`, `styles.css`, و `app.js` الأساسية.
2. بناء واجهة المستخدم الأساسية
   - تصميم نموذج لإضافة المهام وقائمة لعرضها.
3. إضافة وظائف JavaScript
   - تنفيذ إضافة مهمة، عرض قائمة المهام، وتحديث حالة المهمة.
4. التخزين المحلي
   - ربط التطبيق مع Local Storage لحفظ المهام بين الجلسات.
5. تحسين واجهة المستخدم
   - إضافة أنماط CSS وتحسين تجربة المستخدم (Responsive).
6. (اختياري) إضافة واجهة خلفية
   - إنشاء API بسيطة لتخزين المهام على الخادم واسترجاعها.
7. اختبارات ونهائية
   - اختبار الوظائف الأساسية وإصلاح الأخطاء، إعداد المستندات وREADME النهائي.

## كيفية التشغيل
1. افتح الملف `index.html` في المتصفح.
2. استخدم نموذج الإضافة لإدخال مهام جديدة.

---

إذا رغبت، أستطيع إضافة ملفي مثال `index.html` و `app.js` أو ملء Local Storage ببعض المهام التجريبية تلقائيًا.
